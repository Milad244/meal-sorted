# Meal Sorted

## Access
Website: TBD

## Description
**Meal Sorted** is a full-stack website where you can find and create all your meals with automatic nutrition and price estimates, and create a shopping list based on a week of meals. For those who want cheap, nutritious, and time-efficient meal prep, this is the website for you!

## Status
Ongoing. 2026-06-28 to present.

## Resources Used
- Frontend: Next.js/React, TypeScript, TailwindCSS
- Backend: Python (FastAPI)
- Database: PostgreSQL
